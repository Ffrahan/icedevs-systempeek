🧊 System Peek - نمایش اطلاعات سیستم  

این پروژه یک اسکریپت ساده و کاربردی با زبان پایتون هست که اطلاعات پایه‌ای و مهم سیستم‌عامل رو نمایش می‌ده.  
نسخه‌های جداگانه برای ویندوز و لینوکس طراحی شده و هیچ کتابخونه‌ی اضافی لازم نداره.

-------------------------

چه اطلاعاتی رو نشون می‌ده:  
- نام کاربر  
- نوع سیستم‌عامل و نسخه‌ی کرنل  
- مدل پردازنده (CPU)  
- مقدار کل و آزاد حافظه‌ی دیسک  
- آدرس IP محلی  
- مدت زمان روشن بودن سیستم (Uptime)  
- زمان بوت شدن سیستم  
- زمان فعلی  
- نام توزیع لینوکس (در نسخه‌ی لینوکسی)

-------------------------

نحوه اجرای نسخه ویندوز:

python system_peek_windows.py

نحوه اجرای نسخه لینوکس:

python3 system_peek_linux_advanced.py

اجرای نسخه‌ی لینوکس بدون نیاز به دانلود:

curl -sL https://raw.githubusercontent.com/Ffrahan/icedevs-systempeek/main/system_peek_linux_advanced.py | python3
